# Image prompt kit for connorlaughl.in

Purpose: give Connor a ready set of gpt-image-2 prompts for the next visual pass on connorlaughl.in.

Use with DESIGN.md in the repo root. That file is the creative brief and token source. This kit is the prompt deck.

## Global rules

Use these rules for every image.

- No readable text inside the image.
- No logos, trademark marks, team crests, brand marks, or real company materials.
- No private photos, literal wedding photos, client artifacts, screenshots, or proprietary diagrams.
- No faces or realistic portrait of Connor unless Connor supplies and approves a reference.
- No fake metrics, fake customer names, or fake charts with legible numbers.
- Leave negative space for web layout.
- Keep the palette close to black, warm cream, old gold, graphite, clay paper, muted red, and soft blue gray.
- Favor matte photography, scanned print texture, halftone, ordered dithering, paper fibers, terminal glyphs, and editorial artifact energy.

Recommended generation settings:

- Model: gpt-image-2.
- Start with 3 or 4 variants per prompt.
- Generate source images at the largest practical size.
- Export final web assets in AVIF or WebP after processing.
- Keep raw, dithered, and ASCII variants in separate folders.

Suggested asset folders:

- public/visuals/raw
- public/visuals/dithered
- public/visuals/ascii
- public/visuals/exported

## Shared base prompt

Paste this at the end of each prompt unless the individual prompt already repeats it.

Create a high taste editorial image for Connor Laughlin's personal GTM portfolio. Matte black and warm cream palette with old gold accents, graphite shadows, clay paper, subtle oxblood details, scanned print texture, visible grain, and gentle halftone or ordered dithering. The image should feel like an artifact from a working system: tactile, restrained, intelligent, and slightly analog. No readable text. No logos. No faces. No private documents. No fake charts with legible numbers. No glossy SaaS dashboard style. No neon. No photorealistic celebrity likeness. Leave negative space for web layout.

## Prompt 01: homepage hero artifact

Intended placement: homepage hero, right side panel or quiet background specimen.

Aspect ratio: 4:5 or 3:2.

Prompt:

An editorial still life representing a hybrid marketing executive and GTM systems engineer. A matte black desk surface with cream paper cards, thin routing lines, brass binder clips, an old gold pencil, a subtle terminal printout made of abstract glyph blocks, and a small stack of strategy notes with all text blurred beyond recognition. The composition should feel like a boardroom brief crossed with a builder's workbench. Leave the left third or top third as calm negative space. Use shallow depth, soft directional light, visible grain, and restrained analog texture.

Processing notes:

- Make one dithered version with a 6 color palette.
- Make one ASCII density version using only abstract shapes, not readable words.
- Animation idea: fade from clean source to dithered source over 8 to 12 seconds.

Alt direction:

Decorative if used behind the hero. If visible as a panel: "Editorial still life of strategy notes, routing lines, and abstract terminal texture."

## Post generation selection rubric

Pick images that pass these checks:

- They still look good in a 360px wide mobile crop.
- They do not contain accidental readable text.
- They do not imply real client data or private records.
- They look tactile after dithering, not muddy.
- They make the page feel more like Connor, not more like a template.
- They leave enough quiet space for copy and UI.

## Processing recipe

1. Save the original generation in public/visuals/raw.
2. Make a cleaned source crop in public/visuals/exported.
3. Create a dithered version with a 4 to 8 color palette.
4. Create ASCII for the homepage hero artifact, About still life, flagship systems artifact, and proof index texture.
5. Compare source, dithered, and ASCII versions on dark and light themes.
6. Ship only the versions that improve the page at mobile size.

## First implementation recommendation

Start with three assets:

1. Homepage hero artifact.
2. About page personal still life.
3. Flagship systems artifact.

That gives the site a stronger visual point of view without asking every section to carry a new image treatment at once.
